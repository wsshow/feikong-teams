# 安全说明

fkteams 以当前操作系统用户的权限运行。对外部署前启用[登录认证](configuration.md#服务与认证)，并保护应用目录中的配置、登录凭据、会话和日志。Web 登录使用同一应用实例的数据，不提供多用户租户隔离。

## 工具权限

- Web 和交互终端支持危险命令、外部文件访问、Git 写操作与任务分发审批。自动批准类别见[配置指南](configuration.md#工具权限审批)。
- 消息通道默认自动审批，接入前应限制允许使用机器人的用户。后台调度及未配置审批处理器的非交互执行默认拒绝高风险操作。
- 自动审批不取消路径校验、危险命令检测和工具权限元数据。自定义智能体只能使用配置允许的工具。
- MCP 服务和 JavaScript 扩展属于可信管理配置。MCP 的 stdio 进程与远程服务拥有各自的权限，不能假定受内置文件工具的工作区限制。

## 文件与执行边界

文件、文档、Git 和 Excel 默认限制在应用工作区，符号链接不能用于绕过边界。文件工具访问外部绝对路径仍须审批；上传、下载与 HTTP 文件管理不允许逃出工作区。

| 能力 | 主要限制 |
| --- | --- |
| 文档解析 | 输入最多 32 MiB，Office 声明展开内容最多 64 MiB；文本结果最多 100000 个字符，过大范围需分页 |
| Excel | 输入最多 32 MiB，解压最多 64 MiB；通过 `next_row` 和 `truncated` 续读，批量填充失败不保存部分结果 |
| SSH 传输 | 本地路径仅限工作区，单文件最多 1 GiB；校验远程主机密钥 |
| 本地命令 | 按工作区和会话隔离任务，通过稳定任务 ID 查询或停止；取消与关闭会等待所属进程收尾 |

内置 `command` 工具组的 `execute` 的 `yield_ms` 只控制本次等待预算，默认 1 秒、最大 30 秒；`timeout` 控制执行期限。`job` 默认 120 秒，`service` 默认无期限，显式期限最长 24 小时。`background` 表示立即返回；返回后台后，任务由应用管理，后续聊天取消不会终止它。日志只保留最近 4 MiB，可通过 `process_read` 分页读取，停止使用 `process_stop`。

shell、Python 和脚本宿主函数最终使用进程的操作系统权限。工作目录、uv 虚拟环境、Bun 依赖目录和命令风险检测均不构成系统沙箱；需要更强隔离时使用受限用户或容器。

## 分享与备份

文件预览和会话分享可设置密码、期限并主动撤销。分享前检查正文与附件是否包含敏感信息；关闭工具详情只隐藏工具载荷，不会自动清理对话正文中的秘密。密码和 Token 不放入 URL 查询参数。

完整备份应在应用完全退出后复制应用目录，恢复与旧数据升级见[存储说明](storage.md#备份与恢复)。
