# 安全说明

- **文件操作限制**：文件操作被限制在工作目录 `~/.fkteams/workspace/` 下，防止误操作系统文件
- **SSH 连接管理**：`remote` 智能体通过 SSH 连接远程服务器，确保连接信息安全存储和使用
- **MCP 工具隔离**：每个 MCP 服务运行在独立的进程中，可以单独控制启用/禁用
- **工具权限管理**：自定义智能体只能使用配置中明确指定的工具，避免权限滥用
- **日志记录**：所有智能体的操作和输出都会被记录，可以主动输出成 markdown 文件，便于审计和调试
- **工具调用可视化**：所有工具调用都会在终端显示，提供透明度
- **配置文件保护**：请确保 `config.toml` 不被泄露，避免敏感信息外泄

## 内置工具边界

- 文件、文档、Git 和 Excel 的路径参数默认限制在配置的工作区；文件工具访问外部绝对路径仍须经过已有的文件审批。工作区内的符号链接不能用于绕过外部路径限制。
- 文档解析使用私有快照，输入最多 32 MB，Office 归档声明的展开内容最多 64 MB。智能读取最多返回 100000 个 Unicode 字符；按页或按行范围过大时要求缩小范围。文档信息查询只读取元数据，不为估算文本长度提前读取全文。
- Excel 输入最多 32 MB，解压最多 64 MB；表格数据通过有界行迭代读取，使用 `start_row`、`next_row` 与 `truncated` 继续分页。批量填充失败不会保存部分填充结果。
- 命令的显式后台模式同样遵守默认 60 秒、最大 600 秒的执行超时。后台任务通过 `task_id` 查询或终止，只能由同一工作区和会话访问；应用清理会等待进程退出。脚本与命令取消覆盖子进程组。
- 命令风险检测是辅助审批策略。shell、Python 和 JavaScript 代码仍使用运行 fkteams 的操作系统权限；工作目录与依赖环境不等同于系统沙箱。
