# 个人助手

点击 Web 侧栏“助手”进入常驻会话，刷新或重启后继续同一份历史。它可以读取应用工作区、检索以往会话、记忆偏好和跟进交办；普通问答无需创建任务。默认工作区为 `~/.fkteams/workspace`，与启动命令的目录无关。

可以直接说“以后叫你小空”改名，也可使用输入框 `/rename`；`/clear` 清空对话与队列，保留名称和长期记忆。表单、图表与命令说明见[助手交互界面](assistant-ui.md)。

## 能力与协作

常规工作由助手直接完成，复杂子任务按需交给已启用的团队成员，再检查和整合结果。所有操作沿用现有工具权限与审批，成员不可用时不影响基础问答。

技能仍使用现有按需加载机制；外部服务只能通过实际配置的工具或成员接入，不把未连接的功能描述为可用。

## 记忆与任务

长期偏好和可复用经验由助手主动维护，见[主动记忆](memory.md)。需要多步或跨回合完成的交办通过 `task_save` 保存独立任务；`task_list` 查询未完成事项或已完成结果。

任务包含目标、完成标准、来源会话、进展、下一步、结果和可选的调度 ID。创建使用稳定 key 防止重试重复建单；更新要求 ID 和版本，冲突时重新读取。所有状态写入原子持久化，失败不确认成功。

- `pending`：已记录，尚未推进。
- `in_progress`：目标正在推进，不表示当前有后台进程。
- `waiting_user`：等待用户信息或决定，必须记录下一步。
- `waiting_time`：等待已创建的定时任务，必须关联调度 ID。
- `paused`：用户暂停，保留进展。
- `completed`：已交付并记录验证后的结果。
- `failed`：执行受阻，保留原因和继续处理的办法。
- `cancelled`：用户取消。

重启或切换话题后，助手通过任务记录、来源会话与实际环境核对进展，再继续工作。恢复记录不会自动重放已执行的命令或对外操作。暂停、取消目标记录不等于停止实际调度；助手还必须调用相应调度操作。

任务结果可以记录真实交付物的位置与链接，读取记录本身不会访问其中的路径。所有实际文件操作仍通过原有工作区工具与权限检查。

## 后台安排与结果

时间驱动的交办由 `schedule_add` 实际创建安排，`schedule_update` 改期或重新安排，`schedule_result` 分页读取已保存的结果。一次执行时间使用带时区的 ISO 8601，周期安排可以使用 `CRON_TZ=Asia/Shanghai` 等前缀。只有工具成功后才能确认已安排；记录任务的 `waiting_time` 本身不创建调度。

Web 打开且页面可见时会轮询后台结果并显示通知；离线时保留待通知状态。周期任务离线期间的通知合并为最新一次，完整记录仍在任务历史中。通知确认只清除对应运行的待通知状态，网络失败重试确认不会重新执行任务。此功能不代表操作系统推送、邮件或消息通道主动送达。

应用关闭或崩溃导致的运行中断标为失败，并提示核对实际结果后再重新安排。不会自动重放可能已经产生副作用的工作。未确认通知的结果不会因常规过期清理而丢失。
