# 助手交互界面

Web 常驻助手（`/assistant`）支持在消息中生成交互界面，使用 OpenUI 通用组件库。普通回答仍使用 Markdown；模型根据任务选择表达形式，也可以直接指定：

- “把这几个方案做成对比表，按名称筛选。”
- “根据刚才查到的任务数据画趋势图，另一个分页签显示明细。”
- “用步骤和折叠区解释发布流程。”
- “用表单收集时间、范围和通知偏好，范围可以多选。”

界面可包含布局、表格、图表、指标、表单与详情弹窗。图表使用真实查询或用户提供的数据，演示数据需明确标注。

## 使用方式

1. 助手按内容逐步生成界面，必要时包含输入控件、筛选和详情弹窗。
2. 生成期间控件不可提交。生成结束后填写内容，点击提交或卡片按钮。
3. 操作作为下一条用户消息交给同一个助手；已有任务运行时进入 follow-up 队列。
4. 助手继续调用原有工具处理请求，危险操作仍经过独立的审批流程。提交表单不表示操作已完成或已获审批。

每个界面块接受一次对话提交；提交后字段与操作只读，分页、Tabs 等浏览仍可用。已提交值随用户消息保存，重新打开可恢复；未提交草稿仅保留在当前界面。网络失败可重试，结果不明时先检查会话或队列，避免重复提交。

队列中的操作可删除、排序或改为文字；删除后原界面可再次提交。仅常驻助手启用交互渲染，普通聊天、分享页、CLI 和消息通道显示文本。也可直接用文字回复助手。

## 输入框命令

在助手输入框开头输入 `/` 唤起命令菜单，继续输入中文名称或英文命令可筛选。使用方向键选择，Enter 或 Tab 执行，Esc 收起；也可以点击菜单项。

- `/clear`：确认后清空助手的聊天记录、上下文和待处理队列，保留助手名称与长期记忆。助手有运行任务时不可执行。
- `/rename`：打开名称编辑框，名称支持 1–40 个字符，保存后同步更新侧栏和对话中的助手称呼。

命令直接执行界面操作，不作为消息发送给模型。普通会话保持原有输入行为。

## 实现约定

- 每个 `openui-lang` 围栏是完整的 `root = Stack(...)` 程序。渲染器以消息分段 ID 和块序号识别来源，源码沿用消息 Content 和 transcript。
- 表单与输入框共用 `sendChatMessage`。提交消息用 `【助手界面操作】` 前缀及版本化 JSON 保存来源、请求与字段；日期用 `{$date: ISO字符串}` 编码，Web 回放为可读内容。
- 允许 `@ToAssistant` 继续对话、`@OpenUrl` 打开无凭据的 HTTP/HTTPS 链接，以及变量、`@Set`、`@Reset` 和内置数据函数。本地筛选不触发后端工具，工具执行仍走原聊天与审批链路。
- lexer 校验动作白名单、长度和嵌套，提交校验字段类型与体积；流式未完成、提交中、已提交或会话切换时禁用操作。凭据不应放入表单。错误程序提供文字回复入口。

主题遵循 [Web 主题](web-theme.md)。维护 OpenUI 时保留以下边界：

- 完整 layered 样式仅在 `globals.css` 导入一次，顺序为基础重置、OpenUI、项目组件、工具类。
- 组件与 ThemeProvider 统一从 `@openuidev/react-ui` 根入口导入，避免子入口的独立上下文导致 portal 丢失主题。
- 运行时代码按需加载，Vite 保留 devtools 空实现映射与依赖分包边界。升级后验证普通页面加载量、消息混排、弹窗/日期主题和生产构建，防止循环初始化。

## 修改组件与提示词

组件和示例在 `web/src/features/chat/openui/library.tsx` 定义。修改后运行：

```bash
cd web
bun run generate:assistant-ui
bun test src/features/chat/openui
```

脚本从实际组件库生成 `internal/app/agent/catalog/workspaceassistant/openui_prompt.txt`，由 Go 嵌入助手指令。生成文本随源代码维护，前端构建会重新生成；测试检查生成文本与组件定义一致。直接构建 Go 时使用已提交的提示词。

完整验证使用 `make check` 与 `cd web && bun test src`。Go 的 `TestAssistantUIRoundTripPreservesHistoryAndUsesExistingTools` 覆盖跨回合、历史重新加载及原有工具调用；前端测试覆盖混排、流式禁用、提交、失败回滚、队列、历史恢复和渲染边界。

上游参考：[OpenUI 仓库](https://github.com/thesysdev/openui)、[交互接口](https://www.openui.com/docs/openui-lang/interactivity)。
